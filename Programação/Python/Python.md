É uma linguagem de sintaxe enxuta de tipagem dinâmica e com um ecossistema amplo contendo várias bibliotecas nas áreas de análises de dados, machine learning e etc.

# Hello World
Diferente de algumas linguagens como Java, C++ e C, Python tem uma facilidade imensa em reproduzir a tradição dos programadores de printar na tela "Hello World".
```python
print("Hello World")
```



# Snippet simples
Devido a essa linguagem mais enxuta, é possível prototipar facilmente aplicações, incluindo aplicações de cunho numérico e estatístico.
```python
num1 = 3
num2 = 5
resultado = num1+num2
print(resultado) # O print irá mostrar o número 8.
```
Exemplo de um snippet simples de soma feito em python.
